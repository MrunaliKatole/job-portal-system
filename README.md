# 💼 Job Portal System

A full-stack Job Portal web application developed using Java, Spring Boot, React and MySQL.

## 🚀 Technologies Used

- Java
- Spring Boot
- Spring Security
- React.js
- MySQL
- REST APIs
- HTML
- CSS
- JavaScript
- Git & GitHub

## ✨ Features

### 👤 Job Seeker
- User Registration & Login
- Search Jobs
- View Job Details
- Apply for Jobs
- Save Jobs

### 🏢 Recruiter
- Recruiter Registration & Login
- Add Job
- Manage Jobs
- View Posted Jobs

## 🏗️ Project Structure

- `src/` – Spring Boot Backend
- `frontend/` – React Frontend
- `DB_Scripts/` – MySQL Database Scripts
- `pom.xml` – Maven Configuration

## ▶️ How to Run

### Backend
1. Open the project in Eclipse or IntelliJ.
2. Configure MySQL.
3. Update database details in `application.properties`.
4. Run the Spring Boot application.

### Frontend
1. Open the `frontend` folder.
2. Run:

```bash
npm install
npm run dev
